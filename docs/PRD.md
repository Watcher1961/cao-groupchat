# 产品需求

## 用户与目标

面向在本机使用多个 CLI 编码代理的项目负责人（群主）。将 CAO 的 session、terminal 和 agent profile 映射为项目群、成员和职责，让群主在一个中文界面中分派工作、观察回复、安排实现与独立审查。

## 功能范围

- 建群、选择项目工作目录、邀请和移出成员、编辑配置并重启成员。
- 配置 provider、模型、推理强度、订阅或 API 计划、角色、工具权限和职责。
- 群主定向提及或广播；成员回复中的提及触发接力，上限 6 跳。
- 显示成员状态、消息与共享日志；成员可直接追加日志，无写权限者用行首 `[日志]` 请求代写。
- 本机保存群和消息；从本机 CLI 日志汇总用量，按可用价格估算费用，展示可取得的账号额度窗口。
- 支持浅色、深色、跟随系统；后端不可用时可体验演示模式。

第一轮 Git 基线、共享规范、单元测试和集成验收已结案。第二轮五项修复已由群主确认结案，收尾媒体查询 change 修复单独待复审；实际 Tab 循环及故意 CLI 启动失败恢复保留待验证；Codex 支持 low/medium/high/xhigh，Claude Code 另支持 max，留空用 CLI 默认，其他 provider 不显示。公网部署、团队账号系统、自动发布和更多 provider 兼容性承诺仍不在范围。

## 按额度调度（新一轮第 2 项）

按群 `quota_enabled` 默认 false。成员面板提供开关，开启后可设百分比阈值并显示“恢复”或“标记为等额度”；关闭群不显示这些操作，不自动检查、暂停或恢复，不改变原只读额度条。API 同样可读写设置；旧文件缺字段可加载，初始额度数据缺失视为 ok。

成员 `quota_state` 为 ok、near（接近阈值）或 exhausted（等额度），`quota_resets_at` 已知时填写。near/exhausted 卡片显示预计重置时间或“重置时间未知”，需要人工处理时明确提示。near 只暂停新派发，当前轮仍能完成。

优先读取 Codex 账号共享 rate_limits、已开启采集群的 Claude statusLine 快照（含 spend_limit）。任一有效窗口达到 100% 且 resets_at 在未来则 exhausted；可选 `quota_pause_percent` 默认 null，设阈值时达到即 near。终端检测仅支持有本机实际字符串依据的 Codex/Claude，其他 provider 特征待验证。Codex 仅在菜单标题、唯一的 Keep current model 文字及当前编号精确匹配时按键；无法确定时不按键，提示群主。

暂停期间保留原队列，不告警“可能未送达”、不发该成员空闲提醒，不因等待消耗预算或提醒次数。等待累计秒数保存在 automation_state，按成员统计。每次等待只发一次进入等待的系统提示；恢复另发说明，探测到上限时仅追加一次群主处理提示。

已知 resets_at 加默认 120 秒宽限后重新检查；未知时间默认每 900 秒检查，连续 8 次失败后标“需要群主处理”并提及群主，停止自动解除。恢复需要可用窗口或正向终端就绪证据；已知重置已过宽限时，同一条历史限额提示加就绪输入框可确认旧提示已过期，输入框重绘或状态栏刷新不改变首次记录的重置时点，无需发模型请求探测。未知时间缺数据或空输出不解除暂停。群主可强制恢复。

本轮被硬限额确认中断且尚未完成的任务，在恢复后先发一次固定中文 `[自动续接 quota:<群ID>:<次数>]` 提示，再投递原队列后续消息。续接不带原文，沿用该任务的静默属性和接力跳数，经原预算路径计数；预算耗尽则保留在队首。持久化投递令牌防止自动重复，迟到的真实完成回复优先于续接。结构化额度暂停本身不能证明任务中断；已完成的任务不续接。 新任务开始后仍保留在对话历史中的旧限额提示不触发再次暂停；只有本轮投递后新增的提示实例才算新的拒绝。

新增诊断只记录额度元数据和固定动作，不记录终端正文或凭据；原聊天持久化与共享日志仍按已有私有数据规则处理。来源与验证证据见 [任务记录](TASKS.md)，真实 provider 的限额时机联调待验证。

## 插队修复：Hermes 回复与超长输入

Hermes v0.22.5 的 NO RESPONSE 回退只能当作待解析缓冲区，不能作为成员发言。按本轮投递前的 full/last 快照和完整标题/结束页脚识别新一轮，提取 `☤ Hermes` 后的最终答案，去除输入框、进度和状态重绘。优先渲染后的 last；原始 FIFO 含退格、不能可靠还原时不冒充最终正文。仍在 working 的帧继续等待，完成却无法归属/提取时只发一次简短系统提示、不触发转发。旧轮不能重复进入群聊。

所有经本程序发往 CAO input 的消息，包括人工重试的旧 failed/uncertain 作业，按编码后的请求目标 path+query 限制为 14000 ASCII 字节；约 12.5 KB 的中文请求目标应完整投递，只有超出上限时保留可发送前缀并附原字符数和截断说明，不修改原作业正文/接力跳数，不改成 CAO 不支持的请求体。

单条成员回复显示最多 8000 字符，超过时明确注明截断；完整已提取正文保存在本地群聊数据 full_text 中，群详情和列表均不返回该私有字段。旧超长 agent 记录也在读取时限制显示，原本地记录不重写。小消息和 Codex/Claude 完成判定、模型配置保持原行为。

Antigravity CLI 的候选若仅是可精确匹配的已发送输入片段，或是 NO RESPONSE 整屏回退，拒绝作为自身回复；输入尾部之后确有答案时先去除可精确对应的回显。无法精确区分的短重复片段和历史异常仍待真实复测，不用猜测删改正常内容。新增诊断不记录终端正文；样本仅离线只读，测试使用合成数据。
