# 产品需求

## 用户与目标

面向在本机使用多个 CLI 编码代理的项目负责人（群主）。将 CAO 的 session、terminal 和 agent profile 映射为项目群、成员和职责，让群主在一个中文界面中分派工作、观察回复、安排实现与独立审查。

## 功能范围

- 建群、选择项目工作目录、邀请和移出成员、编辑配置并重启成员。
- 配置 provider、模型、订阅或 API 计划、角色、工具权限和职责。
- 群主定向提及或广播；成员回复中的提及触发接力，上限 6 跳。
- 显示成员状态、消息与共享日志；成员可直接追加日志，无写权限者用行首 `[日志]` 请求代写。
- 本机保存群和消息；从本机 CLI 日志汇总用量，按可用价格估算费用，展示可取得的账号额度窗口。
- 支持浅色、深色、跟随系统；后端不可用时可体验演示模式。

本轮是 Git 基线、共享规范、单元测试、集成验收四项工程工作，不新增产品功能。公网部署、团队账号系统、自动发布、更多 provider 兼容性承诺，以及已知缺陷修复均不在本轮范围。推理强度配置尚未支持。

## 验证口径

“已验证”仅限上述日期、CAO 版本、provider 和操作组合，不表示所有兼容性或安全隔离已通过。kiro 等其他 provider、waiting_user_answer 交互均待验证。用量面板的数据来自本机 CLI 日志，并非 CAO 用量 API；Codex 额度是账号共享窗口，Claude Code 日志不提供订阅剩余额度。

任务 3 已通过 22 个隔离单元测试，覆盖安全导入、提及、接力、静默、日志及输出清洗；任务 4 增加 2 个随机端口、临时数据目录的集成测试；模拟 CAO 脚本本身不包含自动断言。模拟通过不代表新增真实 provider 联调或浏览器验收。测试计划、提交和已知问题见 [任务清单](TASKS.md)。
